# Errors

Exceptions thrown by API functions.

## Classes

| Name | Description |
|------|-------------|
| [`Error`](utl-Error.md#error) | Base class of the errors thrown by the API. |
| [`Exception`](utl-Exception.md#exception) | Base class of all exceptions thrown by the libraries. |
| [`GenericException`](utl-GenericException.md#genericexception) | An exception that carries a payload and a message. |
| [`IOError`](utl-IOError.md#ioerror) | [Exception](utl-Exception.md#exception) thrown if a file or folder cannot be accessed. |
| [`CoreError`](vc64-CoreError.md#coreerror) | Exception thrown if a request does not match the state of the emulator. |
| [`MediaError`](vc64-MediaError.md#mediaerror) | Exception thrown if a media file is invalid or not supported. |
